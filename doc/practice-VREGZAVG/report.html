Insight

  • Các bản sửa của lần trước đều có tác dụng: 0 bài sai schema, 0 test bị làm yếu, 0 script phụ trong src/, 0 lần tra web, token lúc chờ của session chính giảm 61%.
  • Test cascade là bẫy cài sẵn trong đề. DECISIONS.md và BUILD_REPORT.md ghi hóa đơn và thanh toán dùng RESTRICT ("deleting a company with financial docs fails loudly instead of destroying history"), nhưng migration 20260702093140_company_delete_cascades_financials đổi sang CASCADE. Test đúng, code sai. Trận 1 sửa test (sai hướng); trận 2 giữ test nhưng không sửa code, nên mọi item bị PARTIAL.
  • Quy tắc "không sửa test" đúng nhưng chưa đủ: agent cần thêm bước tìm hiểu vì sao test có sẵn fail, bằng tài liệu thiết kế trong repo, và sửa code khi code đi lệch khỏi thiết kế.
  • Chi phí bây giờ nằm ở guardian: giảm số lượt duyệt tool của chính đội sẽ giảm thêm khoảng một phần ba tổng token.
