      "title": "Invoice export file standard (accountant CSV), revision 2",
      "body": "Revision 2, effective 2026-10-20. Our accountants moved to a new bookkeeping tool; revision 1 files are rejected by it.\n\n1. Encoding: UTF-8 with a byte order mark (the file starts with bytes EF BB BF). Without the BOM, Excel shows Vietnamese names as garbage.\n2. Delimiter: comma. Line endings: CRLF (LF is also accepted by the importer).\n3. Quoting: RFC 4180. A field that contains a comma, a double quote or a line break is wrapped in double quotes, and every double quote inside it is doubled. Text is never trimmed or altered.\n4. The first row is the header, exactly these nine columns in this order, nothing more:\ninvoice_number,company,currency,issue_date,due_date,total,paid,balance_due,status\n5. One row per invoice in the current selection (for example the company filter on screen), including DRAFT and VOID invoices, in the same order as the screen. An empty selection produces a file with only the header row.\n6. Field rules:\n- invoice_number: as stored.\n- company: the company name exactly as stored.\n- currency: the invoice's ISO 4217 code, upper case (USD, VND...).\n- issue_date, due_date: see KB-FIN-04.\n- total, paid, balance_due: amounts in the invoice currency, formatted per KB-FIN-01. paid and balance_due follow KB-AR-02.\n- status: the status code per KB-INV-03.\n\nExample:\ninvoice_number,company,currency,issue_date,due_date,total,paid,balance_due,status\nINV-0042,\"Studio \"\"Mai\"\", Đà Nẵng\",USD,2026-03-02,,250.00,0.00,250.00,SENT\n\nRevision 1 (header invoice_number,company,issue_date,due_date,currency,total,paid,outstanding,status) is withdrawn. Export files contain client financial data; see KB-SEC-01 for who may obtain them."
